# v3.37.0 - Modal-Based Support System

**Release Date:** January 14, 2026

## Summary
Major update removing the need for Privileged Gateway Intents, lifting the 100 server limit. Support system redesigned with modal-based interface.

## Bot Changes
- New modal-based `/support` command with 4 report categories
- New `/ai` command for AI questions via modal
- No more Message Content Intent required
- 1-hour cooldown on support submissions
- Topic filtering for AI questions

## Impact
- Bot can now join unlimited servers (no approval needed)
- All features work without privileged intents
