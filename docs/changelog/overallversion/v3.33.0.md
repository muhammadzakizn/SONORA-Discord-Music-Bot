# SONORA v3.33.0 - Smart Search & Songs Priority

**Release Date:** January 7, 2026

## Overview
This release focuses on improving search accuracy and ensuring the bot plays the correct audio tracks instead of music videos with long intros.

## Bot Updates (v3.30.0)

### Smart Search Algorithm
- Search now fetches 10 results and scores each by title word overlap
- Best match is automatically selected
- Prevents playing wrong songs (e.g., searching "Face Down" no longer returns "Getting By")

### Songs Priority Filter
- All YouTube Music searches now use the "Songs" section filter
- Ensures audio-only tracks are returned, not music videos
- Eliminates long video intros before songs

### Custom Loading Animation
- New animated Discord emoji for all loading states
- More visually appealing than text-based spinners

- Filter parameter: `sp=EgWKAQIIAQ%3D%3D`
