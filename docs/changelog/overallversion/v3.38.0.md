# v3.38.0 - AI Provider Switch

**Release Date:** January 17, 2026

## Rangkuman
Mengganti AI provider dari Groq ke Perplexity untuk AI Support Bot. Perplexity menggunakan model `sonar-pro` yang lebih powerful dan akurat.

## Perubahan Bot
- Perplexity sebagai AI provider utama (menggantikan Groq)
- Model `sonar-pro` untuk respon lebih akurat
- Fallback chain: Perplexity → DeepSeek → Gemini
- Update environment variables (`PERPLEXITY_API_KEY`)
