# SONORA Bot v3.34.0

**Release Date:** January 11, 2026

## Changes

### Lavalink
- YouTube OAuth with `TVHTML5EMBEDDED` client
- Updated youtube-plugin to v1.16.0
- Disabled deprecated built-in YouTube source
- Fixed "Already connected" error for queue playback
- Increased audio buffer (5s/20s) for smoother playback
- Fixed wavelink track end NoneType error

### Performance
- Lyrics loading uses ThreadPoolExecutor (non-blocking)
- Progress bar no longer freezes during lyrics fetch
- Reduced audio stuttering at start of playback

### Features
- Track duration limit: 15 minutes max
- Queue auto-skips tracks over 15 min

### Bug Fixes
- Fixed `stream_url` AttributeError in loop mode
- Fixed `Player.stop()` coroutine warning
- Fixed loading lyrics indicator for all player paths
