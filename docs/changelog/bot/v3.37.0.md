# v3.37.0 - Modal-Based Support System

**Release Date:** January 14, 2026

## Breaking Changes

### No More Privileged Intents Required!
SONORA no longer requires any Privileged Gateway Intents:
- ❌ Presence Intent - NOT NEEDED
- ❌ Server Members Intent - NOT NEEDED  
- ❌ Message Content Intent - NOT NEEDED

**This removes the 100 server limit!** Bot can now be invited to unlimited servers.

---

## New Features

### Modal-Based Support System
The `/support` command now uses a modern button+modal interface:

- **4 Report Categories:**
  - 🐛 Bug Report (red button)
  - 💡 Feature Request (blue button)
  - 💬 Feedback (green button)
  - ❓ Question (gray button)

- **Features:**
  - Modal forms for structured input
  - 1-hour cooldown per report type
  - Developer notifications via DM
  - Ticket ID for tracking

### New `/ai` Command
Ask AI questions via slash command + modal:
- No DM reading required
- Topic filtering (blocks politics, religion, NSFW, etc.)
- 30-second rate limit
- Powered by Gemini AI

---

## Technical Changes

- Removed `on_message` listener from support.py
- All support interactions use modals (no message reading)
- `/ai` command added to `commands/ai.py`
- Updated `/help` to include `/ai` command

---

## Migration Notes

**For Bot Owners:**
1. Disable all 3 Privileged Intents in Discord Developer Portal
2. `git pull` on server
3. Restart bot
4. Bot can now join unlimited servers!
