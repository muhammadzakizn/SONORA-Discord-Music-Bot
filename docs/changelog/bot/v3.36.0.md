# v3.36.0 - FlaviBot-Style Components V2 Media Player

**Released:** January 14, 2026

## New Features

- **Discord Components V2 Media Player**: Completely redesigned player interface using Discord's new Components V2 system
  - `Container` with accent color for visual hierarchy
  - `Section` with `Thumbnail` accessory showing album artwork
  - `Section` with "Like" button accessory for favorites
  - `ActionRow` with control buttons: Pause, Skip, Stop, Loop, Queue
  - Voice channel name display
  - FlaviBot-inspired clean, integrated layout

## Technical Changes

- Created new `ui/components_v2.py` module:
  - `MediaPlayerComponentsV2` class for building Container/Section structure
  - `MediaPlayerLayoutView` class extending `discord.ui.LayoutView`
  - `create_media_player_v2()` helper function for easy usage
- Updated `commands/play.py` (6 locations) to use Components V2
- Updated `ui/media_player.py` (2 locations) to use Components V2

## Improvements

- Player UI now uses modern Discord Components V2 for cleaner appearance
- Buttons integrated within sections as accessories (like FlaviBot)
- Thumbnail/artwork displayed inline with track info
