# v3.31.0 - Loop Command & Cache Optimization

**Release Date:** 2026-01-10

## New Features

### /loop Command
- `/loop track` - Repeat current track continuously
- `/loop queue` - Repeat entire queue after all tracks finish
- `/loop off` - Disable loop
- Interactive button panel with Track/Queue/Off/Close buttons

### Smart Cache for Loop
- Loop replay uses local cache when available (saves bandwidth)
- Cache check priority: Local → Rclone → Re-stream
- Background caching during first play enables instant loop replay

## Technical Changes

- Added `commands/loop.py` with `LoopMode` enum and `LoopCommands` cog
- Added `_replay_current_track_with_cache()` method in `media_player.py`
- Integrated loop mode handling in `_play_next_from_queue()`
- LOOP_TRACK: Replays current track from cache
- LOOP_QUEUE: Adds finished track to end of queue
