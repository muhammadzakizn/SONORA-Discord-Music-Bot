# SONORA Bot v3.35.0
**Release Date:** 2026-01-13

## 🔧 Bugfixes

### Queue System Overhaul
- **Fixed Race Condition** - Queue transition no longer fails to play next track
- **Fixed Audio Stutter** - Lyrics now pre-fetched BEFORE audio starts (5s timeout)
- **Fixed Track Skipping** - Removed broken `is_playing` check that incorrectly skipped tracks

## 🚀 Improvements

### Enhanced Queue Preprocessor
- Now pre-downloads audio files to local cache
- Checks rclone/cloud cache before downloading
- Uploads to rclone after download for future use
- Clear console logging with emojis for visibility

### Improved Play Flow
1. Request received → Show loading spinner
2. Fetch lyrics (with timeout) → Update spinner
3. Show player with lyrics ready
4. Start audio playback (smooth, no stutter)

### Autocomplete Fix
- Autocomplete now uses Deezer URLs for exact track matching
- No more "wrong song" issues when selecting from autocomplete

## 📋 Console Logging
All queue processing now visible in console:
- 📋 Queue status and track count
- 📥 Tracks queued for processing
- 🔄 Processing start
- ✓ Audio, artwork, lyrics ready status
- ✅ Track fully prepared
