# SONORA Bot v3.30.0 - Smart Search & Songs Priority

**Release Date:** January 7, 2026

## New Features

### Smart Search Algorithm
- Search now fetches 10 results instead of just 1
- Each result is scored based on title word overlap
- Best match (score >= 0.3) is selected
- Prevents playing wrong songs from the same artist

### Songs Priority Filter
- Added YouTube Music "Songs" section filter to all search URLs
- Bot now prioritizes audio tracks over music videos
- No more long video intros before the actual song starts

### Custom Loading Emoji
- Replaced text-based spinner with animated Discord emoji
- `<a:loading3:1458459715981021386>` for all loading states

## Bug Fixes
- Fixed SyntaxError in youtube.py (try/except indentation)
- Fixed search validation logic for title matching

## Technical Changes
- `ytsearch1` → `ytsearch10` with smart matching
- Added `sp=EgWKAQIIAQ%3D%3D` filter parameter to YouTube Music URLs
- Updated loading emoji in `config/constants.py` and `ui/spinner.py`
